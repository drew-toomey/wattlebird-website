# wattlebirdgames.com

Studio website for Wattlebird Games. Plain HTML and CSS, no build step, hosted free on GitHub Pages.

- `index.html`: the home page (studio, Comic Corner, contact)
- `js/site.js`: set `DISCORD_URL` / `STEAM_URL` to switch those buttons on (empty = hidden)
- `CNAME`: the custom domain
- `img/`: real in-game art only (no AI art, no stock)
